## ✨ What it does

- **Browse games** from the best download sites, automatically kept up to date
- **One-click downloads** — pick a game, hit Download, done
- **Auto-install** — unpacks and finds the right executable for you
- **Steam Deck ready** — full controller support, Proton integration, adds games to Steam
- **Mod support** — browse and manage mods from Nexus Mods & Thunderstore *(coming soon)*
- **Beautiful UI** — purple neon sunset theme, smooth and fast

## 📥 Download

Head to the **[Releases](../../releases/latest)** page and grab the latest installer:

> **`Splurge Launcher Setup 0.1.0.exe`**

Run it, install, launch. That's it.

## 🎮 Steam Deck Setup

1. Switch to Desktop Mode
2. Download and run the installer
3. The launcher adds your games to Steam automatically
4. Switch back to Game Mode — your games are there

Full controller support works out of the box: D-pad navigates, A selects, B goes back, LB/RB switch tabs, Y opens search.
